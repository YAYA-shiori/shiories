# ふきだし７・すぷらっしゅすたー

ゴースト「SHIORIES」に同梱しているバルーンです。頭上に出る小さな吹き出しで、話しているキャラクターごとに枠の色が変わります。

## 元になったバルーン

元になったのは、はっぷん氏が作ったゴースト間会話用バルーン「ふきだし７」（2003 年公開）です。「ふきだし７」は、複数のゴーストを同時に出したときでも会話が読めるように、小さく作られています。

このバルーンは、はっぷん氏から同梱のご許可をいただいたうえで、SHIORIES に合うように Ukagaka Tech Team が改修したものです。

はっぷん氏のサイト: http://www.iris.dti.ne.jp/~brook/happen/

## 使い方

SHIORIES と一緒にインストールされ、最初から選ばれています。ほかのバルーンに変えるときは、SSP の右クリックメニューにある「バルーン」から選びます。

## 吹き出しの色

話しているキャラクターに合わせて、枠と線の色が切り替わります。

| キャラクター | 枠 | 線 |
|---|---|---|
| 華和梨 | 黒 | 赤 |
| 里々 | 緑 | 黄土 |
| 文 | くすんだ赤 | 黒 |
| 里珠 | 灰 | 薄い灰 |

地の色は生成り、文字は墨色にそろえています。

## 原作からの変更点

- 頭上に出す左向きの吹き出しだけに絞りました。原作にあった 7 色の吹き出しは入っていません。
- キャラクターごとの配色に塗り替えました。矢印、SSTP のマーカー、オンライン表示も、キャラクターごとの色にしています。
- 入力ボックスの絵を作り直し、左上に Send、Communicate、Teach、Input、Address Bar、Textarea のラベルを入れました。
- 使わなくなった定義を削除しました。

## 配布について

原作の「ふきだし７」は、転載はできるかぎり不許可、配布ページへのリンクは自由、というお約束で公開されています。このバルーンも SHIORIES の一部として配布しているものですので、SHIORIES の外での再配布や、画像のほかの作品への流用はしないでください。
