# SHIORIES Balloon

ゴースト「SHIORIES」に同梱しているバルーンです。頭上に出る小さな吹き出しで、話しているキャラクターごとに上端の帯の色が変わります。

## 使い方

SHIORIES と一緒にインストールされ、最初から選ばれています。ほかのバルーンに変えるときは、SSP の右クリックメニューにある「バルーン」から選びます。

## 見た目

直線だけでできた、シンプルな吹き出しです。角は丸めずに斜めに落とし、影は付けていません。吹き出しの上端に、キャラクターの色の帯があります。

| キャラクター | 帯と枠 | 帯の細線 |
|---|---|---|
| 華和梨 | 黒 | 赤 |
| 里々 | 緑 | 黄土 |
| 文 | くすんだ赤 | 黒 |
| 里珠 | 灰 | 薄い灰 |

地の色は生成り、文字は墨色にそろえています。入力ボックス、スクロールの矢印、SSTP のマーカー、オンライン表示も、同じ決まりで作っています。
